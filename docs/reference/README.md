# Исторические материалы

Эти документы сохранены для требований и исследований, а не как инструкция
запуска текущего прототипа. Их старые статусы, счётчики тестов и ссылки относятся
к архивной реализации. Файлы по старым ссылкам доступны в полной резервной копии,
указанной в `../CLEANUP.md`.

`V1-ACCEPTANCE-MATRIX.md` сохраняет исходные требования, включая No01 до Space.
`V1-EVIDENCE.json` — исторические свидетельства к той матрице.
Два REA-отчёта сохраняют каталог функций и последние выводы о No01.

\LAYOUTSWITCH-MACRO-SCOPE.md\ — первоначальное решение пользователя о составе V1 и исключённых функциях.
\CHAT-OBSERVATIONS-AND-DECISIONS-20261018.md\ — краткая запись ранних ручных наблюдений, которых не было в актуальном roadmap.
