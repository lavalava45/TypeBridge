### Минимальные инфраструктурные зависимости версии 1

Эти подсистемы **не означают перенос всех их оригинальных настроек в первую версию**; требуется лишь минимальный безопасный функционал, без которого пункты 01–13 нельзя считать работающими:

- **№17 (частично):** проверяемая запись и чтение текста в целевом редакторе, защита от гонок, недопущение потери текста, Undo, работа при быстром наборе. Не реализовывать все экспериментальные варианты и все исходные задержки в интерфейсе только ради формального соответствия.
- **№19 (минимум):** запрет исправлений в парольных полях, терминалах и небезопасных целях, исключения по приложению при необходимости; расширенный редактор исключений — после V1.
- **№25 (минимум):** индикация реально выбранной раскладки и состояния автокоррекции без дополнительных тем и пакетов иконок.
- **№31 (минимум):** один процесс/хук, корректный запуск, остановка и освобождение ресурсов. Полная автозагрузка и расширенные режимы выхода — позднее.
- **№32 (минимум):** диагностические события о коррекции, отказах и задержках без накопления приватного набранного текста. Полный UI журнала/трассировки — позднее.

### Обязательные критерии завершения версии 1

1. **Раннее распознавание:** убедительная ошибочная раскладка исправляется во время набора слова, без ожидания пробела; критерии уверенности и неоднозначности проверяются отдельно.
2. **Быстрый непрерывный набор:** первое и следующие слова не пропадают и не портятся, включая ввод без пауз, смену фокуса, отмену и три языка RU/EN/HE.
3. **Отсутствие опасных ложных исправлений:** правильные слова, неоднозначные последовательности, сочетания клавиш и ограниченные поля остаются без непрошеных изменений.
4. **Функциональные сценарии всех №01–13:** демонстрируются не только окна/галочки, но реальные операции; автоматические проверки плюс подтверждённые ручные пользовательские испытания.
5. **Проверка редакторов:** Notepad++, Блокнот, Chrome и веб-поля — проверенные комбинации отдельно; отказ в неподдерживаемом поле не должен портить текст.
6. **Прозрачная готовность:** для каждого пункта фиксировать `not started / implemented / verified offline / verified live`. Запрещено объявлять V1 готовой по одной сборке EXE или успешному одиночному слову.

### Организация ускоренной разработки

- Вместо последовательных мелких патчей — **единая спецификация + крупные функциональные вертикали** с заранее заданными интерфейсами.
- Параллельные области: (а) инкрементальное распознавание + обучение/словари; (б) проверяемые редакторные адаптеры/гонки/Undo; (в) автозамены и специальные правила; (г) настройки, тестирование и упаковка.
- Один интеграционный владелец и автоматический контролёр проверяют, что все критерии достигнуты; нельзя считать ложный `done` успешным завершением.
- Не тестировать реальные глобальные хуки автоматически в рабочем пользовательском сеансе: сначала воспроизводимые изолированные сценарии, затем согласованные живые проверки.

**Принцип согласования:** отсутствие номера в списке исключений не является явным подтверждением каждой его опции. Для V1 выбраны 01–13; оставшиеся 10 блоков — кандидаты на следующие версии. После выбора уточнять вложенные настройки, не раздувая объём за счёт побочных функций.

**Разграничение №18:** исключение большого централизованного редактора сочетаний клавиш не отменяет самих горячих клавиш для сохранённых функций №02, 04, 13 и других. **Приоритетная незакрытая проблема №01:** прежний LayoutSwitch распознаёт при пробеле; это не воспроизводит наблюдаемое в SwitchER64 переключение после нескольких символов во время ввода. Быстрый непрерывный набор уже выявил пропуск первых слов в реальном Notepad++. Успех шести направлений при наборе отдельных слов не считается прохождением этого критерия.

**Разграничение №14 и №06:** убрана самостоятельная функция преобразования регистра по команде пользователя. Исправления регистра как часть **орфографии** в №06 остаются в V1.
