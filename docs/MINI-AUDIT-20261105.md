## Следующие небольшие шаги

1. **R02, пользовательская приёмка:** в выделенном браузерном поле проверить
   `גיאהז → время`, пробел и Pause после пробела, Backspace по неотслеживаемому
   тексту, первые буквы до готовности UIA. Затем быстрый ввод/HKL/Undo R01–R03.
   Агенту для физического ввода нужно отдельное разрешение.
2. **R04, независимый эксперимент:** проверить lifetime/identity адресата,
   контрпример HWND reuse и адресацию отдельных полей браузера средствами
   Windows, без браузерного расширения. Не включать TargetLease в live-hook
   как якобы полное решение; неизвестное/парольное поле запрещает замену.
3. **R17–R18:** сначала модель жизненного цикла отдельного hook-потока и
   shutdown, затем узкая проверка console fallback/изоляции блокирующего API.
   Исправленные deadline-сценарии не считать повторно открытыми без дефекта.
4. **Перед публичной сборкой:** отдельно сверить и зафиксировать незакоммиченный
   R04-прототип и документы; получить воспроизводимый снимок и его проверки.
   После P0 — фиксированный корпус качества R08/R09, затем расширение функций.
