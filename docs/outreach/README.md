# TypeBridge outreach — исследование площадок и учёт результата

Режим на 01.11.2026: **RESEARCH ONLY — NO OUTREACH**. Новый чат может самостоятельно исследовать площадки и менять только локальные исследовательские файлы. Письма, DM, PR, issues, листинги, посты, загрузка файлов, платные заявки и публикации — только с отдельного явного разрешения пользователя.

## Файлы и правило источника истины

- PLATFORMS.csv — основной реестр площадок и их актуального состояния. Уникальный id неизменен, один реальный путь размещения/контакта в одной строке. При разных путях одной платформы создаются разные id.
- CONTACT-LOG.csv — журнал действий. Добавлять **только реально совершённые** обращения/подачи/ответы с timestamp, адресатом, точным содержанием или ссылкой на его сохранённую копию и подтверждающим URL/ID. Не заполнять вымышленными попытками.
- TYPEBRIDGE-OUTREACH-HANDOFF-2026-11-01.md в родительском docs — начало для нового чата.

- **Учёт:** `PLATFORMS.csv`, запись `TB-030`, статус `published` относится **только к меткам самого репозитория**, не к каталогам, постам или сторонним размещениям. `CONTACT-LOG.csv` не меняется: никому не писали, заявки не отправляли.

Сопоставить будущие GitHub Traffic `views/referrers` и скачивания релиза с исходным уровнем; не приписывать изменения именно меткам без данных об источнике.
- **Следующее действие:** поиск релевантных запросов и сайтов остаётся исследовательским; никаких новых публичных правок, публикаций и обращений без отдельного разрешения.

## Поля PLATFORMS.csv

- id, priority: постоянный ключ и P1/P2/P3; P1 — ранний качественный охват, P2 — подготовить, P3 — ограниченно релевантен/есть явный барьер.
- category, platform, audience, opportunity_url, submission_url, method: что это и через какой **проверенный** канал возможно размещение.
- cost: free, paid_option, unknown, free_with_conditions; «нет указания платы» — не равнозначно гарантированной бесплатности.
- requirements, rationale, blockers: точные условия и смысл для пользователей TypeBridge; неизвестное писать unknown.
- verified_on, source_url: дата и первичная страница проверки условий. Не подменять источник ссылкой на выдуманный контакт.
- prior_contact_audit: pending / verified_none / found_prior; по умолчанию pending — прежняя переписка вне файлов не проверена.
- contact_status: not_started / approved / drafted / sent / followup_sent / replied / declined / no_reply. not_started относится **только к этой новой кампании**, не ко всей истории проекта.
- listing_status: unknown / not_submitted / submitted / pending_review / published / rejected / removed / not_applicable. Для внешних площадок — unknown до проверки внешних записей. Исключение: подтверждённые метки своего GitHub-репозитория (TB-030) имеют published **только применительно к публичным topics**, не к стороннему листингу.
- interest_status: unknown / none_observed / expressed / review_planned / coverage_published / declined; нельзя ставить expressed по одному просмотру.
- last_contact_date, external_record_url, next_step, notes: факты, подтверждение, предстоящее действие.

## Поля CONTACT-LOG.csv

event_id, platform_id, utc_datetime, action, recipient, channel, subject_or_summary, full_text_or_snapshot, destination_url, evidence_url, response_date, response_summary, listing_url, interest_status, followup_due, notes.

Когда отправка будет отдельно разрешена: перед действием проверить PLATFORMS.csv + CONTACT-LOG.csv + реальные страницы/письма на дубли, сохранить точный текст сообщения; после отправки записать подтверждение, затем обновить итоговый статус PLATFORMS.csv. Ответы — отдельные строки в журнале. Если нет подтверждения доставки, отмечать как unconfirmed, не sent. Для составления черновика или открытия страницы публикации также не нажимать Submit.

## Границы сведений и прозрачность

Отдельно различать: найденная площадка ≠ заявка отправлена ≠ модерация приняла ≠ карточка опубликована ≠ аудитория проявила интерес. Не придумывать email, метрики, аудиторию или дату ответа. Не утверждать, что внешней публикации нет, только на основании поисковой выдачи. Повторно проверять правила площадки непосредственно перед контактом.

Не рекламировать alpha.7 как гарантирующую безопасность паролей или универсальный быстрый ввод: R04/No01 открыты. Не публиковать пользовательские данные, Diagnostics, личные словари, локальные пути, скриншоты с персональными данными. Основной публичный URL: https://github.com/lavalava45/TypeBridge/releases/tag/v0.1.0-alpha.7.

## Первичная очередь исследования

P1 — простые релевантные каталоги для open-source Windows-инструмента (LibHunt, Alternative.me, AlternativeTo); отдельный технический материал DEV #news после подготовки объективного текста. AlternativeTo имеет длительную бесплатную очередь и платную приоритизацию — не оплачивать.

P2 — качественная история «Show HN», Product Hunt и сообщества разработчиков с проверкой риска публичного alpha; SourceForge, WinGet/Scoop/Chocolatey потребуют сопровождения пакетов и условий подачи. PortableApps требует отдельной проверки формата.

P3 — условные curated lists: например 0PandaDEV/awesome-windows требует как минимум 50 GitHub stars; на 01.11.2026 у TypeBridge было **0 звёзд** (проверено через GitHub API), поэтому сейчас не предлагать.

Площадки/условия, о которых известно только из вторичных каталогов, держать в предварительном исследовании и не записывать как проверенный маршрут подачи, пока не найдена официальная страница.
