# TypeBridge — непокрытые исполняемые операторы в изменённом коде (07.11.2026)

**Назначение:** построчный учёт всех *исполняемых операторов внутри текущих изменённых диапазонов*, не достигнутых именно объединённым инструментированным pytest-прогоном (`coverage-focused.json`). База объединяет несколько инструментированных запусков: исходный большой набор **305 PASS / 1 deselected**, native-блок **115 PASS / 1 deselected**, проблемный общий набор **117 PASS / 4 FAIL** (до исправления фикстуры) и адресный повтор **5 PASS / 15 deselected** после исправления. Их результаты **не складываются как число уникальных тестов**, а выполненные строки падающего теста не являются успешной проверкой. Другие ранее пройденные unittest, 261 GUI-тест и изолированные Win32 пробы представлены отдельными журналами. **Отсутствие покрытия не означает дефект.**

Ранее отчёт ошибочно включал лишь целиком неисполненные диапазоны и пропускал частично исполненные ветви. Здесь учтены и полностью, и частично неисполненные операторы; точные отдельные строки сохраняются в столбце `uncovered_statement_lines` CSV.

- Всего записей текущих диапазонов (ханки + символы новых файлов): **646**.
- Полностью покрытые диапазоны: **311**; частично покрытые с пропусками: **96**; целиком непокрытые исполняемые диапазоны: **79**.
- Неинструментированные диапазоны: **71**; без исполняемых операторов: **59**; чистые удаления: **30**.
- Все строки с хотя бы одним пропущенным оператором: **175 записей** в **136 логических группах**, **725 уникальных пар «файл:строка»** (перекрывающиеся диапазоны не удваивают количество).
- Первопредки коммитов: **286** ханков, сопоставлены с текущими контрактами только статически; их промежуточные версии не инструментировались.

- Удалённые строки и декларативные/пустые ханки не являются исполняемыми операторами текущего Python-кода.

- AST-кандидаты вызова могут ссылаться на одноимённые чужие методы; это ориентиры для ревизии, а не подтверждённый runtime call graph.
- HIGH означает риск разрушительного действия (ввод/буфер/фокус/SendInput) и приоритет проверки, не наличие ошибки.
- Private desktop Win32, модели и статический анализ не подтверждают физический глобальный hook, Chrome DOM, настоящий Notepad++ или Undo в нём.
