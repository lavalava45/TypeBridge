# TypeBridge 0.1.0-alpha.6 — Windows x64 portable

Download **TypeBridge-0.1.0-alpha.6-windows-x64.zip**, extract the entire folder
and run `TypeBridge.exe`. Python and an installer are not required.
Russian, English and Hebrew keyboard layouts must be installed in Windows.
The folder must be writable. Keep `data/` alongside the EXE.

## Changes since alpha.5

- Public and Diagnostics are built separately. Only **Public** is distributed;
  its executable excludes the modules that record typed words and browser text.
- Keyboard corrections, manual word cycling, snippets and direct layout commands
  use the guarded background input worker. Notepad++ early transactions run after
  the keyboard callback returns, retaining document checks and native Undo groups.
- Safer handling of uncertain replacements, non-text controls, clipboard privacy
  markers and journal timeouts; improvements to tray recovery and Windows shortcut
  detection.
- A source-verified dictionary cache speeds up repeat preparation. On the developer's
  machine, preparation measured 11.15 seconds cold and 1.35 seconds cached; startup
  time on other computers will vary. Changed sources rebuild the cache.
- Journal configuration, reading and decryption run in the background, with paged
  history. Disabling is confirmed after any already-started commit completes.
- The caret flag uses a separate cancellable process so a hung accessibility
  provider can be stopped and retried. Settings and tray support RU/EN/HE.

## Package and verification

The ZIP includes Public, external RU/EN/HE dictionaries, frequency data,
dictionary source notices and licenses, example dictionary packs, three language
guides, the matching source archive and build manifests. Code is MIT; dictionary
licenses and attribution are included separately. Local settings, personal word
lists, logs, journals and the Diagnostics EXE are excluded.

The release pipeline requires every unittest module on freshly prepared public
data, frozen self-tests for both profiles (including a geometry-only helper process
test), public EXE inspection and ZIP/private-file checks. `BUILD-MANIFEST.json`
records the source commit and tests; `SHA256SUMS.txt` verifies the portable ZIP.

## Alpha limitations

- **Browser password-field correction is not reliably protected.** The common UIA
  password guard is disconnected from live correction. Disable correction before
  entering secrets and exclude sensitive applications. Public excludes text tracing;
  this does not make password-field correction safe. See
  [privacy details](https://github.com/lavalava45/TypeBridge/blob/main/docs/PRIVACY.md).
- Before-space correction is experimental and off in a fresh profile. Automated
  tests do not establish physical typing compatibility in every editor.
- The executable is unsigned. Journal snapshots use Windows DPAPI and cannot be
  moved to a different Windows user as readable history.
- A fresh profile starts with autocorrection, clipboard history, journal and quick
  search off. Enable only the features you need and save settings.

**По-русски:** распакуй ZIP целиком и запусти `TypeBridge.exe`. Все три словаря
уже внутри папки `data`; отдельно скачивать их не нужно. Это альфа-версия:
автоисправление до пробела экспериментальное, защита парольных полей браузера
ненадёжна — перед вводом секретов отключай исправления. Диагностика набранных
слов в публикуемом Public EXE отсутствует.
