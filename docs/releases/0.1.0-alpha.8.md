# TypeBridge 0.1.0-alpha.8 — Windows x64 portable

This alpha focuses on input recovery, clipboard/search hotkeys and caret-indicator resilience. Russian, English and Hebrew are included; compatible data-only language packs can extend the available languages, with 1–3 active at a time.

## Changelog since alpha.7

- **Recover the last word after lost tracking.** Supported UI Automation fields can recover a complete word at the caret after Backspace over untracked text or typing before field metadata became ready. Pause can also recover the last word after a space. The `גיאהז → время` case is covered with the real dictionaries and simulated field APIs. Unsupported, changed, password or uncertain fields are skipped; this is not universal browser acceptance.
- **Safer modifier and input recovery.** Physical Shift/Ctrl/Alt/Win releases are no longer held for replay. Transaction ownership prevents an old operation from cancelling or clearing a newer one. Partial-send accounting and KEYUP-only cleanup avoid replaying uncertain text; worker-start failures preserve recoverable input for an explicit retry.
- **Additional field checks.** Correction paths recheck their field/guard/layout before subsequent layout changes or recording a successful replacement. These checks reduce follow-up mistakes; they cannot retract text already accepted by another application or make UIA and SendInput atomic.
- **Clipboard/search hotkeys separated from the tray.** A dedicated hook message loop owns installation and shutdown. Window capture and process-exclusion lookups run in a separate metadata worker. If a fresh matching context is unavailable, the original shortcut goes to the application rather than being swallowed or replayed later.
- **Quick Search fallback and deadlines.** Recognized console/terminal windows and unavailable identity metadata independently block fallback Ctrl+C, even if optional application exclusions were removed. Direct UIA selection reading remains available. Delayed safety checks cannot authorize a late Copy or browser opening.
- **Caret indicator resilience.** Healthy helpers survive focus changes. Repeated startup failures stop automatic retries and produce a diagnostic record. A timed-out MSAA fallback is paused for the affected window for 60 seconds while native caret reading and other windows remain available. Fixed API-stage markers help distinguish provider timeouts from Python startup failures without recording document text.
- **Clearer tray status.** A temporary correction-limitation banner expires from the menu; the active degraded state remains visible in the tray tooltip while the limitation still applies.

## Download and upgrade

Download **`TypeBridge-0.1.0-alpha.8-windows-x64.zip`**, extract the entire folder to a writable location and launch `TypeBridge.exe`. Keep `data/` beside the EXE. Python, an installer and administrator rights are not required.

For an existing installation, exit TypeBridge through **Exit / Выход** in the tray before replacing files. Preserve your `TypeBridge-data/` folder and review language/startup settings after upgrading. The EXE is unsigned, so Windows may show a publisher warning.

## Known limitations — why this remains an alpha

- **R04/password safety remains open.** UI Automation checks and global keyboard injection cannot atomically bind a replacement to a browser DOM element. Scripted focus changes or incorrect accessibility metadata can still defeat field checks. Do not rely on this alpha to protect confidential input in every application; exit TypeBridge before entering secrets if this risk is unacceptable. Turning off correction alone does not disable its separate optional clipboard/journal services.
- **No01/physical acceptance is incomplete.** Fast typing, focus/layout changes and Undo/Redo have not been accepted across the full application matrix. Early correction before Space remains experimental. Synthetic tests and frozen self-tests are not a substitute for real-input acceptance.
- **Some providers remain slow or unsupported.** During a window's MSAA pause its flag may disappear if no native caret is available. The original intermittent Python-startup message has not been conclusively reproduced or attributed; retry control and provider isolation do not establish its original cause.
- **Quick Search has bounded follow-up actions, not forced API cancellation.** An already-blocked third-party API can keep a worker busy until it returns. Terminal recognition is not a guarantee for every embedded terminal. The addressed R04 transport prototype stays disabled by default.

## Verification and release files

The tagged Windows workflow runs all unittest modules in separate processes against fresh public dictionary data, verifies frozen Public and Diagnostics profiles, and audits package contents. Only the **Public** EXE is distributed. `BUILD-MANIFEST.json` records the exact commit, test outcome, dependency versions, dictionary provenance and file hashes. The public package excludes personal settings, local history and typed-word tracing.

Release assets: the portable ZIP, **`SHA256SUMS.txt`** and **`BUILD-MANIFEST.json`**. Verify the ZIP against `SHA256SUMS.txt`. This CI package is built independently from the personal local EXE and dictionaries.
