# TypeBridge 0.1.0-alpha.11 — Windows x64 portable

**Alpha prerelease.** This is the first downloadable build following
v0.1.0-alpha.9. Tag `v0.1.0-alpha.10` did not produce a release because
its Windows CI correctly blocked publication on a missing UI translation.
All alpha.10 changes are included here, together with the localization fix.

## Changes since alpha.9

- **Hyphen and plus boundaries.** `-` and `+` now finish a recognized
  layout-mismatched word while keeping the punctuation. Examples:
  `Rfrjt-n` can become `Какое-т`, and `vfif+cfif` can become `маша+саша`.
- **Keep unknown compound identifiers unchanged.** A suffix of
  `x-ghbdtn`, `x+ghbdtn`, or `hello-ghbdtn` is not autocorrected if the
  preceding component was not itself corrected. Existing words like
  `hello-world` and `hello+world` remain unchanged.
- **Lower correction overhead.** In simple mode, the correction path avoids
  a redundant Win32 `GetClassNameW` lookup. Physical typing speed was not
  measured by this change.
- **Better frozen diagnostics.** The isolated UI Automation helper self-test
  now returns bounded stage/failure codes instead of only
  `uia_helper_ok=false`. Diagnostics contain no entered text. An earlier
  intermittent helper startup failure remains under investigation;
  a public release must pass both frozen-profile self-tests.
- **Accurate and localized exclusions copy.** The exceptions window now
  clearly describes the deliberate simple-mode password-field limitation,
  including translations into English and Hebrew. The original `alpha.10`
  CI failure was reproduced and covered by a new localization regression.

## Accepted security and compatibility limits

The active `SIMPLE_SWITCHER_MODE=True` intentionally **does not block
correction in password fields**. This is an explicit user decision following
earlier false-positive protection that blocked ordinary editors; do not
reactivate the guard as an incidental fix. Non-atomic `SendInput` vs browser
DOM focus changes, unsupported UIA TextPattern providers, and full Undo/Redo
remain open compatibility issues. Automated tests do not establish physical
input correctness in every website, including Facebook. Windows binary is
unsigned.

## Download, installation, and verification

The verified release should include exactly three downloadable assets:

- `TypeBridge-0.1.0-alpha.11-windows-x64.zip`
- `SHA256SUMS.txt`
- `BUILD-MANIFEST.json`

Check the ZIP checksum, extract the complete portable folder, and run
`TypeBridge.exe`. Included public dictionaries and language packs must
stay next to the executable. Keep existing private `TypeBridge-data/`
separate; do not upload settings, clipboard history, or custom dictionaries.
Exit the old TypeBridge from its tray menu before replacing the running EXE.
The GitHub release is assembled by Windows CI from tagged, committed source
and independently retrieved redistributable dictionaries. A developer's
local executable and personal data are never release inputs.

## По-русски

После alpha.9 исправлены дефис и плюс при автоматическом переключении,
защищены от ложной коррекции составные идентификаторы, исключён ненужный
Win32-вызов и добавлена диагностика frozen UIA. Также исправлены
английская и ивритская локализации окна исключений, из-за которых
первый релизный прогон alpha.10 не прошёл.

**Защита парольных полей остаётся отключённой по решению пользователя.**
Реальную корректность в Facebook и полную матрицу Undo/Redo ещё следует
проверить отдельно.
