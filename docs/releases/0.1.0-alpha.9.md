# TypeBridge 0.1.0-alpha.9 — Windows x64 portable

**Alpha, not stable.** This release focuses on manual word/layout cycling,
browser selection handling, input/clipboard recovery and lower overhead on the
keyboard path. It includes Russian, English and Hebrew and supports verified
data-only language packs (1–3 active languages). Compared with the published
**v0.1.0-alpha.8** (5 November 2026):

## Changes since alpha.8

- **One manual word-cycle command (Pause).** Convert the current word or
  previously typed word, including words separated by spaces; cycle through
  active layouts and preserve a supported caret position. Manual conversion
  works even when automatic correction is turned off. The old split commands
  are consolidated, and the enable/disable-autocorrect shortcut is configurable.
- **Selected text in supported editors.** A Scintilla selection adapter
  supports Notepad++ without the earlier incorrect legacy x64 text-range ABI
  that caused an observed crash. A separate bounded UI Automation TextPattern
  path reads/verifies browser selections. Repeated Pause after the selection
  collapses has extra caret/word checks. TextPattern support depends on the
  particular editor; unsupported fields can safely refuse the replacement.
- **Safer recovery on failed edits.** Additional checks reject stale/changed
  selections and focus. Input-worker release, no-KEYUP Pause handling,
  partial delivery, clipboard hotkeys and stale asynchronous replies have
  targeted fixes. This reduces known failure modes but cannot guarantee the
  fate of a partially delivered global `SendInput` packet.
- **Clipboard recovery and Quick Search.** Temporary clipboard replacement
  has an encrypted Windows DPAPI checkpoint with explicit tray recovery.
  Search/clipboard workers handle timeouts and stale results more carefully;
  an unresponsive third-party reader is not forcibly cancelled.
- **Punctuation and layout ambiguity.** More conservative recognition avoids
  changing only the middle of a token if an apparently trailing punctuation
  key could be a letter in the target layout. Manual conversion remains
  available when the automatic decision is ambiguous.
- **Input-path performance.** Skip early dictionary work before the fourth
  physical key; avoid redundant candidate checks and Win32 class reads.
  The detailed negative dictionary classifier no longer runs inside the
  keyboard hook with ordinary debug enabled; optional deep diagnostics use
  a bounded off-hook worker and emit metadata-only reason codes. Window titles
  are read only when the title filter is active. A controlled read-only
  microbenchmark found a 13.8% reduction in median `_context()` time
  (59.4→51.2 microseconds, 1200 paired calls). **This is not a measured 13.8%
  improvement in end-to-end physical typing latency.**
- **Tray/UI refinements.** More consistent language selection icons and
  descriptions, unified word-cycle controls and updated hotkey settings.
- **Clean Windows CI compatibility.** Source-only self-test now generates
  the registered Windows UI Automation typelib with `comtypes` when a fresh
  Python installation lacks its generated wrapper; the frozen executable
  still requires the bundled audited module. Failed self-tests report their
  diagnostic JSON rather than hiding it behind empty stderr.

## Important security and reliability warning

**This alpha uses `SIMPLE_SWITCHER_MODE=True`. It intentionally disables the
previous password-field guard (`ES_PASSWORD` / UIA `IsPassword`) and persistent
native-write quarantines in the active correction path. TypeBridge may try to
correct text even in a password field.** Do not use it as a guarantee of
confidential-field safety; fully exit TypeBridge before entering secrets if
you cannot accept this risk. This is a behavioral and security-policy change
from earlier strict-guard descriptions.

The existing UI Automation checks cannot atomically bind a global `SendInput`
write to a browser DOM element. Focus changes, unsupported/misreported
accessibility providers, uncertain delivery and undo behavior remain open
issues (**R04 / No01 / R10**). Targeted real typing in Chrome and multiple
Pause operations was reported working by the developer, and response felt
better, but this does not establish cross-application physical-input
acceptance, quantitative Chrome latency, or complete Undo/Redo correctness.
Early correction before Space remains experimental.

This build is **unsigned**. Windows may show a publisher warning.

## Download, upgrade and verification

Download **`TypeBridge-0.1.0-alpha.9-windows-x64.zip`** from this release,
extract the **entire** folder to a writable location, and run `TypeBridge.exe`.
Keep `data/` and `bundled_language_packs/` with it. No Python installation or
administrator rights are required for ordinary use.

When upgrading, **Exit / Выход** TypeBridge from its tray menu first. Preserve
the existing `TypeBridge-data/` folder (settings, custom words and local
history) rather than overwriting or uploading it. Check autostart and active
languages after moving the EXE. Your existing encrypted journal is tied to
its original Windows user.

This release is built by the tagged Windows CI from **committed source** and
verified open-data dictionaries, **not** from the developer's local
`dist/TypeBridge.exe`. The release must contain exactly these three assets:

- `TypeBridge-0.1.0-alpha.9-windows-x64.zip` — Public profile only;
- `SHA256SUMS.txt` — expected hash for the ZIP;
- `BUILD-MANIFEST.json` — source commit, test results, dependency/dictionary
  provenance and file hashes.

Check the ZIP SHA-256 against `SHA256SUMS.txt`. The public ZIP must exclude
personal settings/history and typed-content tracing. The release workflow
must pass the isolated source regression suite, both frozen profile checks
and package integrity checks before publication; see
[release actions](https://github.com/lavalava45/TypeBridge/actions/workflows/release.yml)
and the included manifest for this specific build.

## По-русски

После alpha.8: одна клавиша Pause для перебора раскладок текущего/предыдущего
слова и поддерживаемого выделения, исправленный x64 API Notepad++, проверка
выделения UIA в Chrome, восстановление буфера через DPAPI, защита от устаревших
операций и меньше лишней работы на каждой клавише. Раннее распознавание
и `_context()` оптимизированы; **ускорение всего физического ввода количественно
не измерено**.

**Критически важно:** текущий простой режим намеренно **не проверяет
парольность поля**. TypeBridge способен изменять текст и в поле пароля.
При вводе секретов полностью выходи из приложения. R04/No01 и полная
приёмка Undo/Redo остаются открытыми. Скачивай полный ZIP, проверяй
SHA-256 и сохраняй свой `TypeBridge-data/` при обновлении.
