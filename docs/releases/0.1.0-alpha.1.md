# TypeBridge 0.1.0-alpha.1 — Windows x64 portable

Download `TypeBridge-0.1.0-alpha.1-windows-x64.zip`, extract all files and open
`TypeBridge.exe`. Python installation and separate dictionary downloads are not
required. Enable **Включить автоисправление**, then use **Сохранить настройки**.
Russian, English and Hebrew keyboard layouts must be installed in Windows.

[English guide](../../README.md) · [Русская инструкция](../../README-RU.md) · [הוראות בעברית](../../README-HE.md)

The package includes:

- TypeBridge.exe with RU/EN/HE open frequency dictionaries embedded.
- Plain-text copies of those dictionaries and source attribution in `data/`.
- Default settings, three language guides, MIT and third-party license notices.
- Matching source-code ZIP and build manifest. The separate SHA256SUMS file
  records the portable ZIP's SHA-256 hash.

This is an unsigned alpha. Public dictionaries use FrequencyWords/OpenSubtitles,
not the local research dictionaries extracted from a third-party application;
correction decisions may differ.
Ambiguous words such as `nfr` (RU «так» / HE `מכר`) are preserved. Before-space
correction is experimental, Notepad++ only, and starts at four letters.
Multiline expansion and Undo still need validation in individual editors.

Code: MIT. Frequency data: CC BY-SA 4.0, attributed to Hermit Dave / FrequencyWords
and OpenSubtitles 2018 contributors. Personal settings, templates and dictionaries
are not included. The private working installation is not replaced by this build.
