# TypeBridge 0.1.0-alpha.7 — Windows x64 portable

TypeBridge corrects words entered in the wrong keyboard layout on Windows.
**Russian, English and Hebrew are included**; they are examples of the
language system, not its permanent limit. Additional languages can be installed
from compatible, validated data-only v1/v2 language packs. Select **one to
three active languages** and install their matching Windows keyboard layouts.
The included AR/ES sample packs are demonstrations, **not** production-quality
Arabic/Spanish dictionaries or evidence of physical typing acceptance.

Download `TypeBridge-0.1.0-alpha.7-windows-x64.zip`, extract the **whole**
folder to a writable location, and launch `TypeBridge.exe`. No Python,
installer or administrator rights are needed. Keep `data/` next to the EXE.
For an existing portable profile, preserve your `TypeBridge-data/` directory;
do not overwrite it with an empty folder. Fully exit TypeBridge through its
tray menu before replacing an older version, and review startup and language
settings after upgrading.

## Changes since alpha.6

- **Extensible languages:** install, update, remove and restore independent
  language packs. Manifest, file-hash, alphabet, language-ID and source-license
  checks guard loading and transactions. Changing the active set takes effect
  after a full TypeBridge restart. Additional-language correction remains
  subject to language-pack quality and per-layout testing.
- **Browser input restored:** removed the overly broad browser-wide block.
  Ordinary browser and compatible desktop text fields can use automatic and
  manual word correction again. Direct keyboard-layout commands do not depend
  on permission to replace existing text.
- **More focused password checks:** native Windows password styles remain
  blocked; browser and custom fields use per-element UI Automation metadata
  before correction, including further checks in the background worker.
  Unverified or stale fields are skipped rather than modified. **This is not
  a guarantee that every browser password or DOM-focus race is protected.**
- **Undo, editing and resilience:** improved Scintilla/Notepad++ Undo/Redo,
  recovery after Backspace, native editor correction and bounded input
  recovery. Input may be left unchanged if a safe edit cannot be established.
- **Interface:** updated descriptions of optional journal limitations, a
  user-visible program event log, multilingual settings, configurable active
  language indicators and an updated TypeBridge banner. The journal still does
  **not** capture browser HTML text fields; this does not disable browser
  layout correction.
- **Release validation:** the Windows CI pipeline passed all **119 unittest
  modules** and frozen Public/Diagnostics verification on the candidate code.
  Packaging also checks source integrity, licences, SHA-256 hashes and
  exclusion of personal content and typed-word tracing from the public EXE.

## Privacy, limitations and compatibility

- **Alpha only.** Windows UI Automation cannot atomically bind an edit to an
  HTML/DOM element. A scripted focus change or incorrect accessibility metadata
  can still cause a password-field safety failure. Do **not** rely on this
  version to handle confidential text safely in every application. If that
  risk is unacceptable, exit TypeBridge before entering secrets. Disabling
  autocorrection alone does not disable its separate clipboard/journal tools.
- Early correction before Space remains optional and experimental. Passing CI
  and selected real-input trials does not certify every editor, focus change,
  speed or physical-keyboard sequence. Full No01/R04 acceptance remains open.
- Clipboard history, the encrypted input journal, quick search and related
  services are **separate, opt-in features**. The journal is local and Windows
  DPAPI-bound; quick search sends explicitly selected queries to the chosen
  browser provider. Review the [privacy details](https://github.com/lavalava45/TypeBridge/blob/main/docs/PRIVACY.md).
- The EXE is **unsigned**, and Windows may display a publisher warning.
  This is a portable package, not an installer. Windows x64 and installed
  keyboard layouts are required.

## Verification and files

The release provides the portable ZIP, `SHA256SUMS.txt` and
`BUILD-MANIFEST.json`. Compare the ZIP hash with `SHA256SUMS.txt`; the manifest
identifies the exact source commit, dictionary provenance and build results.
Only the **Public** EXE is shipped, not the internal Diagnostics build.
