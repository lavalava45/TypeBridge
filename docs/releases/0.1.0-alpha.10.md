# TypeBridge 0.1.0-alpha.10 — Windows x64 portable

**Alpha prerelease.** This release follows v0.1.0-alpha.9 and focuses on
punctuation boundaries, correction-path overhead, and build diagnostics.

## Changes since alpha.9

- Hyphen (`-`) and plus (`+`) can end a layout-mismatched word and preserve
  punctuation during correction: for example, `Rfrjt-n` converts the initial
  physical word to `Какое-т`, while `vfif+cfif` can become `маша+саша`.
- Avoid automatically correcting the suffix of unknown compound identifiers
  such as `x-ghbdtn`, `hello-ghbdtn`, or `x+ghbdtn` when the prefix was not
  converted. Ordinary English compounds such as `hello-world` stay unchanged.
- Avoid a redundant Win32 `GetClassNameW` query in simple-mode correction.
- Frozen UI Automation helper self-tests now identify the failed stage and
  failure class with bounded diagnostic codes. No field text is logged by
  this diagnostic. A previously observed intermittent failure remains under
  investigation; verified releases must pass the frozen self-tests.
- Clarify application exclusions in the GUI. In the active simple mode,
  password-field protection remains **intentionally disabled** at the user's
  express request. Do not re-enable password guards as part of this release.

## Security and compatibility limitations

`SIMPLE_SWITCHER_MODE=True` intentionally does not inspect password fields.
The application may attempt layout correction in a password input; users
must accept this behavior. The non-atomic `SendInput` / browser DOM race and
unsupported editor TextPattern behavior remain known limitations. Neither
automated tests nor a frozen self-test establish physical-input correctness
for every website or editor. Physical Facebook/Notepad++ acceptance remains
open. This Windows binary is unsigned.

## Download and verification

Download `TypeBridge-0.1.0-alpha.10-windows-x64.zip` together with
`SHA256SUMS.txt` and `BUILD-MANIFEST.json` from this GitHub release. Check the
ZIP SHA-256 against the checksums. Extract the entire portable directory;
keep its `data/` and `bundled_language_packs/`. Keep your existing private
`TypeBridge-data/` (preferences, lexicon, history) separate and do not upload it.
Before upgrading an existing installation, choose **Exit** from the running
TypeBridge tray menu. This package should be produced by tagged Windows CI
from committed sources and independently retrieved redistributable dictionaries,
not copied from any developer's personal `dist/TypeBridge.exe`.

The public release must include exactly three downloadable assets: the
Windows ZIP, its SHA-256 checksum file, and the build manifest. The source
and release gates must succeed before GitHub publication.

## По-русски

В версии alpha.10 улучшена обработка `-` и `+`, сохранены составные
идентификаторы с неизвестным префиксом, удалён лишний запрос Win32 при
исправлении слова и расширена безопасная диагностика сборки.

**Защита парольных полей сознательно остаётся отключённой.** Исправление
может сработать даже при вводе пароля. Это принятое ограничение продукта,
а не регрессия, которую нужно автоматически устранять. Реальный ввод
в редактор Facebook и полная матрица Undo/Redo ещё требуют проверки.
