# TypeBridge: режим обычного переключателя, 07.11.2026

Решение пользователя: **не откатывать текущий код**, не удалять старые
реализации, но отключить для запускаемого приложения проверки парольных
полей и длительные защитные карантины, мешающие автокоррекции и Pause.

## Активная конфигурация

В `typebridge_app.py`: `SIMPLE_SWITCHER_MODE = True`.
Режим передаётся GUI и CLI при создании `LiveHook`; сохранённые пользовательские
настройки не переписываются. Модельные/изолированные тесты без флага по-прежнему
используют исторический строгий код, который остаётся доступен.

- Фоновый `PasswordFieldGuard`/UIA metadata watcher **не запускается**.
  Убраны проверка `IsPassword` и `ES_PASSWORD` в контексте активного поля,
  парольные проверки перед `SendInput` и обязательность UIA permission для
  любого обычного браузерного поля. Исключения по имени парольных менеджеров
  не применяются в этом режиме, остальные пользовательские исключения живы.
- `_quarantine_native()` и `_native_blocked()` не устанавливают/не читают
  постоянный запрет на коррекцию, нет `native_blocked_scopes` и глобального
  `native_edit_disabled`. Не создаётся `native_pending_recovery`, и остаток
  очереди предыдущей операции не блокирует последующие слова и Pause.
- Текущая низкоуровневая очередь **не удалена**: она используется временно
  только во время off-hook отправки для порядка физического ввода. При сбое
  операции её невыданные события **не сохраняются для последующего повтора**.
- Для обычной коррекции и ручного переключения выбран `SendInput` вместо
  `NativeEditBridge` и строгого UIA caret-preflight. Pause использует
  запомненное слово. Для Chrome выделенный текст обрабатывается отдельным
  ограниченным UIA read/verify без проверки `IsPassword`: идентичность фокуса,
  диапазон выделения и сохранённый RuntimeID сверяются перед одним Unicode
  пакетом. Подписка на парольные UIA события в simple-route не запускается.
- Отладочная запись содержания слов и browser readback не активируются даже
  в диагностическом профиле simple-mode.

## Ограничения

Это **сознательный отказ от защиты паролей**. TypeBridge может корректировать
набор в поле пароля. Кроме того, отсутствие карантина **не делает отдельную
неудачную транзакцию безопасной**: при смене фокуса или частично успешном
`SendInput` всё ещё возможен потерянный символ или неточное исправление.
Модельные тесты не доказывают поведение физической клавиатуры и Chrome.
Сначала проверить на безвредном тестовом тексте, а не на важном документе.

По желанию вернуться к строгому экспериментальному режиму можно отдельно,
сменив один флаг и заново собрав программу; старый код остаётся на месте.
