# Аудит TypeBridge, 24 октября 2026

Исходная точка: `adf8357`, main. Проверены все 76 отслеживаемых Python-файлов
на синтаксис; выполнен поиск точек ввода/изменения текста, запуска процессов,
сохранения данных и сетевого доступа. Отдельно разобраны общий hook/context,
метаданные паролей, три транспорта замены, словари, настройки/миграция,
исключения, шаблоны, буфер, поиск, дневник и релизный скрипт.
Это инженерный аудит и фоновые регрессии, а не независимая сертификация
безопасности или проверка каждого приложения физической клавиатурой.

## Подтверждённые дефекты и изменения

| Наблюдение | Результат |
| --- | --- |
| Каждый клик/Tab создавал обязательную паузу 150 мс | Пауза удалена. Разрешение требует нового ответа UIA; время начала запроса передаётся помощником. Ответ, начатый до клика, отбрасывается, включая гонку между потоками. |
| Любой отказ context, включая собственное окно, помечал ввод пропущенным | Карантин относится только к отказу проверки конкретного поля. Смена HWND/клик и разделитель сбрасывают его; модификаторы не создают пропущенное слово. |
| Обычные переходы unknown/safe засоряли лог | Краткая проверка не логируется. Собственное окно не порождает уведомлений защиты. Сообщения остаются для пароля, устойчивого отказа и восстановления помощника. |
| Помощник запускался один раз и мог навсегда замолчать | Добавлен надзор: завершение, отсутствие ответов, повторный запуск с задержкой; до свежего safe разрешения нет. Причины различимы в Snapshot.reason. |
| Кеш имени только по PID | Удалён: имя определяется заново, PID reuse не наследует старое разрешение. |
| Обычный SendInput и ручной цикл могли использовать устаревший контекст | Непосредственно перед записью повторно проверяются поле, раскладка и ревизия защиты. |
| При частичном SendInput на границе слова повторялся разделитель | Не повторять неопределённую запись; отпустить последний частично отправленный keydown, подавить соответствующий keyup. Полностью неотправленная пачка пропускает исходную клавишу. |
| Два красных теста baseline | Исправлена __new__-фикстура кареточного индикатора. Ожидание для уникального английского `a` приведено к действующей политике однобуквенных слов; движок под старое ожидание не менялся. |
| Нет «поясни» | Добавлено небольшое явное дополнение RU; пороги и разрешение неоднозначностей не ослаблены. |
| Публичный релиз обходил unittest | Полный набор тестов теперь обязателен на свежей публичной базе до упаковки, затем self-test источников и EXE. |

## Защита и совместимость: границы доказательств

- В пассивном наблюдении исправленный помощник дал 34 safe-образца за 4 секунды,
  завершился без оставшегося процесса/потока. Текст/клавиши не читались,
  фокус не менялся. Это не реальная проверка парольного поля конкретного сайта.
- Пароль, непроверенное поле, чужой HWND и устаревший ответ по-прежнему запрещают
  преобразование. Если начать слово раньше ответа после смены фокуса, оно может
  остаться без исправления: хвост не подменяется отдельно. Без чтения секретного
  префикса восстановить его безопасно невозможно. Фиксированной 150-мс паузы нет.
- NativeEdit/Scintilla проверяют документ/каретку; SendInput подтверждает отправку
  событий, а не итоговый документ. Модельные проверки покрывают продолжение слова,
  быстрый следующий токен, Backspace, границы, HKL, смену фокуса и отказы.
  Поведение Undo и физического ввода во всех сторонних редакторах не доказано.
  Рабочий checkpoint не заменён; ядро раннего распознавания не переписано.
- Дневник не подключён к общему UIA guard: у него отдельные whitelist редакторов,
  проверка нативного ES_PASSWORD, класса и повторная проверка цели после чтения.
  Чтение браузеров не добавлялось. Расширение списка не делает поле поддержанным.
- История буфера — отдельная opt-in функция. Проверяет процессы-владельцы и
  сигналы исключения из истории, но не может гарантировать происхождение
  скопированного секрета из браузерного поля. Общий UIA guard переключателя не
  означает универсальную защиту истории; это уточнено в описании приватности.
- Частичный SendInput остаётся неопределённым изменением: автоматического
  отката/повтора нет. Тесты не превращают общий транспорт в гарантированную
  совместимость со всеми возможными приложениями.

Локальный CURRENT-STATE.md помечен историческим; канонический статус —
FEATURE-STATUS.md. Черновик alpha.3 сохранён до замещающего проверенного релиза.
