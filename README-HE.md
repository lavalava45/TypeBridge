# TypeBridge — הוראות שימוש

TypeBridge היא תוכנה מקומית ל־Windows לתיקון מילים שהוקלדו בפריסת מקלדת שגויה.
הגרסה הנוכחית תומכת ברוסית, באנגלית ובעברית. בקוד המקור ניתן לבחור גם את שפת
הממשק: רוסית, עברית או אנגלית; זמין בחבילות החל מ־`v0.1.0-alpha.3`. המדריך מסביר
גם את הכפתורים ברוסית שבגרסת ההורדה הקיימת. שפות נוספות מתוכננות להמשך.

[English](README.md) · [Русский](README-RU.md) · [הורדת התוכנה](https://github.com/lavalava45/TypeBridge/releases)

## הורדה והפעלה ללא Python

תגי גרסאות חדשים מפעילים בנייה ופרסום אוטומטיים של ZIP ל־Windows x64, הכולל
EXE, מילונים פתוחים, הוראות בשלוש שפות, רישיונות וסכום ביקורת SHA-256.
אין צורך בהתקנה, ב־Python או בהרשאות מנהל לשימוש רגיל. ההגדרות נשמרות
ב־`%LOCALAPPDATA%\TypeBridge`, ולא בכונן הנייד לצד קובץ ה־EXE.
[פרטים על הבנייה האוטומטית](docs/RELEASING.md).

בקוד המקור הנוכחי נוסף חלון **חיפוש מהיר**: הפעל את התכונה, סמן מילה או ביטוי
ולחץ על **Ctrl+Alt+G**. ניתן לשנות את קיצור המקשים. Google מוגדר כברירת מחדל;
ניתן להוסיף מנועי חיפוש ומילונים באמצעות כתובת HTTP/HTTPS הכוללת `{query}`.
תחילה נעשה שימוש בסימון טקסט של Windows UI Automation. אם השדה אינו תומך בכך,
נעשה שימוש בהעתקה רגילה, בשחזור פורמטי הלוח הנתמכים ובתצוגה מקדימה לפני השליחה,
ללא מתאמים נפרדים לכל עורך. אם אי אפשר לשחזר את פורמט הלוח, הפקודה מבוטלת
עם הודעה. התכונה כלולה בחבילות החל מ־`v0.1.0-alpha.3`; גרסת `alpha.1` ישנה יותר.

לשונית **פרטיות** בהגדרות מסבירה את הגישה למקלדת ואת גבולות ההגנה.
קרא את [הסבר הפרטיות](docs/PRIVACY.md#עברית) לפני הפעלת היסטוריית הלוח או היומן.
כיבוי התיקון האוטומטי אינו מכבה את התכונות הנפרדות האלה.

1. פתחו את דף ההורדות ובחרו את גרסת Windows x64.
2. הורידו את קובץ ה־ZIP ששמו מתחיל ב־`TypeBridge` — לא את ארכיון קוד המקור.
3. חלצו את כל הקבצים לתיקייה רגילה ופתחו את `TypeBridge.exe`.
4. ודאו שב־Windows מותקנות פריסות מקלדת לרוסית, לאנגלית ולעברית.
5. סמנו **`Включить автоисправление`** כדי להפעיל תיקון אוטומטי.
6. לחצו על **`Сохранить настройки`** כדי לשמור את המצב להפעלה הבאה.

החבילה כוללת את קובץ ההפעלה ואת המילונים. אין צורך להתקין Python או להוריד
מילונים בנפרד. גרסת האלפא אינה חתומה דיגיטלית.

## הכפתורים העיקריים

| הכיתוב בממשק | משמעות |
|---|---|
| `Включить автоисправление` | הפעלה או השהיה של התיקון האוטומטי |
| `Сохранить настройки` | שמירת ההגדרות |
| `Свернуть в трей` | הסתרת החלון והשארת התוכנה באזור ההודעות |
| `Выход` | סגירה מלאה של התוכנה |
| `Мои слова и исключения` | מילים אישיות ומילים שאין לתקן |
| `Горячие клавиши` | קיצורי מקשים לבחירת שפה |
| `Индикация` | הצגת דגל ליד סמן הטקסט |
| `Автозамена и шаблоны…` | קיצורים והרחבת טקסט |

סגירת חלון ההגדרות באמצעות X מסתירה אותו; היא אינה מסיימת את התוכנה.
כדי לפתוח אותו שוב, השתמשו בסמל שבאזור ההודעות. להפסקה מלאה בחרו `Выход`.

## תיקון פריסת מקלדת

ברוב היישומים התיקון מתבצע לאחר רווח או סימן מפריד. למשל, הקלדת `akuo`
בפריסה אנגלית יכולה להפוך ל־`שלום`. אם קיימת מילה אפשרית ביותר משפה אחת,
התוכנה עשויה להשאיר את הטקסט ללא שינוי.

תיקון לפני הרווח הוא אפשרות ניסיונית ב־Notepad++, במסמכי UTF-8 רגילים
עד 64 ק״ב. הוא מתחיל ממילה בת ארבע אותיות; מילים בנות שלוש אותיות אינן
מתוקנות במסלול המוקדם. אפשרות נפרדת, כבויה כברירת מחדל, מוסיפה תמיכה
ניסיונית ביישומים אחרים; יש להפעיל גם את האפשרות הראשית לתיקון לפני רווח.
שדות אחרים משתמשים באותה החלפת מקלדת SendInput כמו בתיקון אחרי רווח.
התאימות בפועל לדפדפנים, הגדרות Windows ו־Electron עדיין לא נבדקה.

**למה להשאיר את האפשרות כבויה?** כשהיא כבויה, התיקון מתבצע רק בסיום המילה
(למשל לאחר רווח או סימן פיסוק). בדיקת המילה השלמה עשויה להפחית תיקונים
מוקדמים ושגויים, ולהימנע ממנגנון העריכה הניסיוני ב־Notepad++ ובשדות RichEdit50W.

מילים קצרות ודו־משמעיות עדיין דורשות שיפור: `nfr` יכול להתאים גם ל־`так`
ברוסית וגם ל־`מכר` בעברית. בחירה על פי שפת המשפט עדיין לא מומשה.

## תיקון ידני וקיצורי מקשים

- `Pause` מחליף את פריסת המילה האחרונה במחזור רוסית, אנגלית, עברית.
  אפשר לבחור מקש אחר בהגדרות.
- `F8` מנסה לתקן את המילה שמוקלדת כעת, אם נמצא מועמד יחיד במילונים.
- `Ctrl+Shift+F1` בוחר רוסית, `Ctrl+Shift+F2` אנגלית ו־`Ctrl+Shift+F3` עברית.
  אפשר לשנות או לבטל את הקיצורים בלשונית `Горячие клавиши`.

פקודות ידניות דורשות שמנוע התוכנה כבר הופעל. לחיצה בעכבר, שינוי שדה או
הזזת הסמן עשויים לאפס את זיכרון המילה האחרונה.

## קיצורים ותבניות

פתחו `Автозамена и шаблоны…` דרך ההגדרות או תפריט הסמל:

1. סמנו `Включить автозамену и шаблоны`.
2. הזינו קיצור, למשל `//email`, ואת הטקסט הרצוי, למשל כתובת הדוא״ל שלכם.
3. סמנו `Разворачивать сразу, без пробела` להרחבה מיד לאחר האות האחרונה.
   אם הסימון מבוטל, ההרחבה ממתינה למפריד.
4. לחצו על `Сохранить и применить`.

יש להפעיל גם את התיקון האוטומטי הראשי. התחילו קיצור אחרי רווח או בתחילת
שדה חדש. אפשר לבחור התאמה מדויקת לאותיות גדולות וקטנות. התבנית מוכנסת
כטקסט מילולי; תצוגת מעברי שורה והתנהגות Undo תלויות ביישום ועדיין בבדיקה.

## אפשרויות נוספות

- תיקון CapsLock מקרי: `hELLO` הופך ל־`Hello` ו־CapsLock נכבה לאחר השלמת המילה.
  האפשרות מיועדת לרוסית ולאנגלית; מילים שכולן באותיות גדולות נשארות ללא שינוי.
- דגל ליד סמן הטקסט: פעיל רק אם היישום מספק את מיקום הסמן.
- הפעלה עם Windows: `Запускать с Windows — в трей`. מצב התיקון השמור משוחזר.

## נתונים, מילונים ורישיון

בקוד הנוכחי אפשר לבחור את שפת הממשק בחלק העליון של ההגדרות:
**Русский / עברית / English**. הבחירה נשמרת ומעדכנת מיד את ההגדרות,
מגש המערכת וחלונות הכלים. בעברית הממשק מיושר מימין לשמאל.
השינוי אינו משנה פריסות מקלדת, מילים אישיות או תוכן תבניות.
התכונה תיכלל בבנייה הבאה של קובץ ההפעלה.

ההגדרות, המילים האישיות והתבניות נשמרות ב־`%LOCALAPPDATA%\TypeBridge`.
בעת המעבר מהשם הישן LayoutSwitch, הקבצים הישנים מועתקים אם עדיין אין קבצים
חדשים; הם אינם נמחקים. התוכנה אינה משתמשת בשירות ענן לתיקון הטקסט.

בקוד הנוכחי נוסף יומן טקסט אופציונלי, לפני בניית קובץ ההפעלה הבא.
הוא כבוי כברירת מחדל. דרך `Дневник ввода…` אפשר להפעיל שמירת תמונות מצב
של שדות טקסט ב־Notepad וב־Notepad++ כל שתי שניות, עם הצפנה למשתמש Windows
הנוכחי וניקוי אוטומטי אחרי מספר ימים לבחירה (ברירת מחדל: 7).
אפשר לצפות, להעתיק ולמחוק רשומות. שדות סיסמה ושדות לא מוכרים מדולגים;
דפדפנים עדיין אינם נתמכים. כיבוי מפסיק את הקריאה והשמירה, אך אינו מוחק
רשומות קיימות. ייתכן שהשינויים האחרונים בין תמונות המצב לא יישמרו.

## הפעלה מקוד המקור

נדרשים Windows x64 ו־Python 3.12 עם tkinter. הפריסות לשלוש השפות חייבות להיות
מותקנות ב־Windows. הריצו מתוך תיקיית הפרויקט:

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 prepare_dictionaries.py
py -3.12 typebridge_app.py --self-test
py -3.12 typebridge_app.py
```
