# TypeBridge — RU / EN / HE

[English](README.md) · [הוראות בעברית](README-HE.md) · [Готовая сборка Windows](https://github.com/lavalava45/TypeBridge/releases)

Для запуска без Python скачай ZIP TypeBridge со страницы Releases, распакуй
все файлы и запусти `TypeBridge.exe`. Открытые словари уже включены. Первая
публичная сборка — неподписанная альфа; она использует открытую частотную базу,
которая отличается от локальной исследовательской базы.

Новые теги версий автоматически выпускают ZIP для Windows x64: EXE, открытые
словари, инструкции на трёх языках, лицензии и SHA-256. Установка, Python и права
администратора для обычной работы не нужны. Настройки остаются в
`%LOCALAPPDATA%\TypeBridge`, а не на флешке рядом с EXE.
[Как устроена автосборка](docs/RELEASING.md).

Текущий прототип автоматически исправляет слово, набранное в неверной
раскладке, и переключает язык между русским, английским и ивритом.

Список работающих функций, незакрытых пунктов и следующая очередь:
[docs/FEATURE-STATUS.md](docs/FEATURE-STATUS.md).

Пробный режим «Исправлять до введения пробела» включается отдельной галочкой
с последующим «Сохранить настройки». По умолчанию выключен. Прежний путь действует в обычном
UTF-8 поле Scintilla Notepad++, без выделения, виртуальной каретки и режима
перезаписи, при документе до 64 КБ. Дополнительная галочка «Раннее исправление
в других приложениях (эксперимент)» подключает общий клавиатурный способ:
для остальных полей используется та же замена SendInput, что после пробела.
Реальная совместимость с браузерами и Windows Settings ещё не подтверждена.
При словарной неоднозначности ранней замены нет.
Режим работает на строчных буквах: уверенное целое слово от 4 букв либо
единственное уверенное продолжение от 5. Текст заменяется напрямую через
Scintilla в Notepad++; для RichEdit сохраняется нативная замена. В этих путях
подтверждаются исходный текст у каретки, итоговый документ/каретка и HKL.
Общий SendInput-путь подтверждает отправку пачки и HKL, но не читает итоговый текст.
При отказе до записи текущая клавиша пропускается обычно; неопределённая запись
не повторяется. Таймаут отключает ранний режим до перезапуска движка.
Первая самостоятельная проверка пользователя дала положительный результат.
Быстрый ввод, Undo и все шесть направлений ещё не подтверждены отдельно.

Запуск: `START-TYPEBRIDGE.cmd`, затем кнопка «Включить автоисправление».
Запускатель предпочитает `dist/TypeBridge.exe`; при его отсутствии использует
Python 3.12. Кнопка «Остановить» отключает глобальный перехват.

## Ежедневное использование

Язык интерфейса выбирается вверху настроек: **Русский / עברית / English**.
Выбор сразу сохраняется и обновляет настройки, трей и дополнительные окна.
Для иврита используется расположение справа налево. Язык интерфейса не меняет
раскладки и содержимое личных словарей. Функция добавлена в исходники,
до следующей общей сборки EXE.

- **«Исправлять до введения пробела» (пробный режим):** исправляет подходящие
  слова прямо во время набора, не дожидаясь пробела. **Зачем оставлять выключенным?**
  При отключении программа проверяет слово после его завершения (например, на
  пробеле или знаке препинания). Это может уменьшить число преждевременных
  ошибочных исправлений и исключает использование экспериментального механизма,
  доступного в Notepad++ и отдельно включаемого общего клавиатурного пути.
**Дневник текста — в исходниках, до следующей общей сборки EXE.** Кнопка
«Дневник ввода…» в главном окне и трее. По умолчанию выключен. При включении
сохраняет зашифрованные снимки активного поля Блокнота/Notepad++ раз в 2 секунды;
список разрешённых приложений можно расширить, но неизвестные и парольные поля
пропускаются, браузеры пока не поддерживаются. Шифрование привязано к текущему
пользователю Windows. Есть просмотр/копирование, удаление записей и автоочистка
старше 1–365 дней (по умолчанию 7, при работающем дневнике). Отключение прекращает
чтение и запись; существующие записи остаются до очистки. Последний ввод между
снимками может не сохраниться. Подробные ограничения — в feature status.

- Флажок у текстового курсора: вкладка «Индикация» → «Показывать флажок
  раскладки рядом с текстовым курсором» → «Сохранить настройки».
  Отключается той же галочкой. Работает независимо от автоисправления,
  не забирает фокус и пропускает клики. Если приложение не отдаёт положение
  текстовой каретки, флажок скрывается; возле мыши вместо каретки не появляется.

В основном окне три кнопки: «Включить автоисправление», «Остановить»,
«Сохранить настройки». Если исправления выключены через трей/горячую клавишу,
кнопка включения снова доступна для возобновления. Отдельной кнопки паузы нет.

- На вкладке «Мои слова и исключения» галочка «Учитывать регистр» добавляет
  только точное написание: например, `MiXeD` не совпадёт с `mixed`.
  Без галочки слово/исключение работает независимо от регистра.
- На вкладке «Горячие клавиши» настраиваются прямые команды RU/EN/HE.
  По умолчанию Ctrl+Shift+F1 — RU, Ctrl+Shift+F2 — EN, Ctrl+Shift+F3 — HE.
  Выбери сочетание, введи своё (например, Ctrl+Alt+1) либо «Отключено» и нажми
  «Сохранить сочетания». Эти команды не преобразуют текст и действуют при
  запущенном переключателе, включая паузу автоисправления.

- После запуска отметь «Включить автоисправление». Это тот же переключатель,
  что «Автоисправление» с галкой в трее; отдельного режима «Старт» нет.
  Кнопка «Сохранить настройки» запоминает состояние галки. При следующем запуске,
  в том числе с Windows, включённое состояние запускает движок автоматически,
  выключенное оставляет автоисправление выключенным.
- «Свернуть в трей» и крестик окна скрывают настройки; переключатель продолжает работать.
  Флаг текущей раскладки виден независимо от автоисправления, также на паузе
  и при остановленном переключателе. Двойной щелчок открывает настройки;
  меню содержит «Автоисправление» с галкой, «Раскладка», настройки и выход.
  Галка появляется после успешного запуска; повторное нажатие включает паузу.
  Строка состояния и подсказка значка показывают загрузку и ошибки запуска.
  Повторное нажатие «Автоисправление» снимает галку, следующее — включает обратно.
  Отдельных команд остановки и паузы в трее нет. «Выход» закрывает приложение.
- В подменю «Раскладка» перечислены доступные Windows раскладки, включая
  варианты одного языка. Текущая отмечена галкой. Выбор применяется к приложению,
  из которого открыт трей, и работает также при выключенном автоисправлении.
  Если окно уже закрыто или пользователь переключился в другое приложение,
  запрос отменяется. Новые раскладки программа не устанавливает.
- `Ctrl+Alt+Pause` ставит исправления на паузу и возобновляет их.
- Опция «Исправлять случайный CapsLock: пРИВЕТ → Привет» действует для RU/EN
  после пробела или другого разделителя, если CapsLock включён и слово известно.
  Исправляет регистр и выключает CapsLock. Полностью заглавные слова и исключения
  не меняет. По умолчанию выключена; применяется через «Сохранить настройки».
- Опция «Запускать с Windows» добавляет автозагрузку для текущего пользователя:
  запуск в трей с сохранённым состоянием автоисправления. Сними галку и сохрани настройки,
  чтобы отключить. По умолчанию выключена. Если приложение перемещено в другую
  папку, сохрани настройки из нового расположения, чтобы обновить путь.
- `Pause` вручную перебирает последнее набранное слово по кругу
  RU → EN → HE → RU, без словарных догадок. Работает до пробела, после пробелов
  и после автоисправления. Знаки вокруг слова сохраняются. Клавиша выбирается
  в настройках, изменение применяется кнопкой «Сохранить».
  Работает и при паузе автоисправления, если движок уже запущен.
  Клик, навигация курсора, смена поля, Enter/Tab или постороннее редактирование
  сбрасывают последнее слово. После продолжения вручную изменённого слова
  программа не исправляет отдельно его хвост. Текст остаётся только в памяти.
- `F8` пробует исправить текущее набираемое слово до пробела, если найден один
  словарный кандидат. После пробела и при изменении позиции курсора эта команда
  не восстанавливает предыдущее слово. F8 можно отключить в настройках.
- Во вкладке «Мои слова и исключения» выбери RU/EN/HE и добавь своё слово
  либо запрет на его исправление. Изменения применяются сразу, также доступно удаление.
- **«Автозамена и шаблоны…»** открывает отдельное окно из настроек или трея.
  Включи функцию, задай сокращение (например `//email`) и текст (`name@domain.com`),
  затем нажми «Сохранить и применить». Можно добавить несколько правил, менять
  и удалять их, учитывать регистр сокращения и вводить многострочный текст.
  «Разворачивать сразу» заменяет сокращение после последнего символа; если
  снять галку — после пробела или разделителя. Применяется без перезапуска.
  Требуется включённое автоисправление. Вводи сокращение с начала поля или
  после пробела, в соответствующей раскладке. Backspace отменяет распознавание
  до следующего пробела. Шаблоны хранятся в `%LOCALAPPDATA%\TypeBridge\snippets.json`;
  первоначально функция выключена, правил нет. Вставка переносов строк зависит
  от редактора; физическая совместимость и единый Undo пока не подтверждены.
- Приложения можно исключить по имени процесса, например `code.exe`.
- Кнопка «Сохранить» сохраняет параметры и применяет их к работающему движку.

Пользовательские настройки и словарь находятся в `%LOCALAPPDATA%\TypeBridge`,
единые для исходников и EXE. Рядом с EXE поставляются только начальные настройки;
повторная сборка не затирает личные данные. Для полного завершения используй «Выход».

## Текущая граница

В текущих исходниках добавлено отдельное окно **«Быстрый поиск…»**: включи
функцию, выдели слово или фразу и нажми **Ctrl+Alt+G**. Сочетание настраивается.
По умолчанию Google; можно добавить поисковики и словари с HTTP/HTTPS-шаблоном
URL, содержащим `{query}`. Сначала читается выделение через Windows UI Automation.
Для поля без такой поддержки есть общий способ: штатное копирование, восстановление
поддерживаемых форматов буфера и предпросмотр перед отправкой. Отдельных адаптеров
под редакторы нет. Если формат буфера нельзя восстановить, команда явно отменяется.
Эти изменения ждут общей
сборки EXE; опубликованный архив пока не обновлялся.

На вкладке **«Приватность»** описаны доступ к клавиатуре, необязательное
сохранение данных и границы защиты. Подробности:
[Приватность и доступ к вводу](docs/PRIVACY.md#русский). Выключение
автоисправления не выключает отдельно включённые историю буфера и дневник.

Исправление происходит на пробеле, Enter, Tab или знаке конца слова.
Раннее исправление до пробела доступно в Notepad++ и через отдельную настройку
в других приложениях. Без неё остальные поля исправляются на границе слова.
Это не подтверждает совместимость со всеми
браузерами и редакторами. Подробности: [docs/FEATURE-STATUS.md](docs/FEATURE-STATUS.md).

## Файлы

- `typebridge_app.py` — окно, hooks, исправление текста и смена раскладки.
- `engine.py` — выбор однозначного кандидата по словарям.
- `incremental_recognition.py`, `early_scintilla.py` — раннее распознавание и замена в Notepad++.
- `build_confident_words.py` — сборка частотных фильтров RU/EN/HE.
- `runtime_safety.py`, `single_instance.py` — защита от конкурирующего запуска.
- `user_lexicon.py` — личные словари и исключения, подключённые к движку и GUI.
- `tray_win32.py` — работа в трее и флаги RU/EN/HE.
- `tray_layouts.py` — список раскладок Windows и ручной выбор для сохранённого окна.
- `data/` — локальные словари и исключения; `confident_he.txt` используется.
- `typebridge-settings.json` — режим, ограничение по окну, исключённые процессы.
- `build_hebrew_dictionary.py` — подготовка ивритского словаря из локального корпуса.
- `test_*.py` — только проверки оставшегося кода.
- [docs/FEATURE-STATUS.md](docs/FEATURE-STATUS.md) — состояние функций и очередь разработки.

## Разработка и проверки

Нужны Windows x64 и Python 3.12 с tkinter. Зависимости: `psutil`, `pywin32`, `Pillow`.

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 prepare_dictionaries.py
py -3.12 typebridge_app.py --self-test
py -3.12 -m unittest discover -p "test_*.py"
```

Эти проверки не ставят глобальные hooks. Для живой проверки нужно отдельное
разрешение пользователя; см. [AGENTS.md](AGENTS.md).

Сборка: `build-typebridge.ps1`. Используется локальный PyInstaller из
`.build-deps`, если он установлен, иначе пакет из выбранного Python.
Зависимости сборки: `requirements-build.txt`.

Словари не входят в Git. `prepare_dictionaries.py` подготавливает открытые
частотные списки FrequencyWords/OpenSubtitles для трёх языков. Существующие
словари скрипт не перезаписывает. Корпусные списки могут содержать ошибки;
они не являются орфографическим словарём. Локальная исследовательская база RU/EN
из SwitchER не распространяется. Лицензии и источники — [THIRD-PARTY.md](THIRD-PARTY.md).

Код TypeBridge распространяется по MIT. Прежнее имя — LayoutSwitch.
При первом запуске файлы настроек, личных слов и шаблонов копируются из
`%LOCALAPPDATA%\LayoutSwitch` в `%LOCALAPPDATA%\TypeBridge`, если новых файлов
ещё нет. Старые файлы не удаляются и новые не перезаписываются.
